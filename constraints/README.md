# Dependency constraints

Use [cpu-wsl-py314.txt](cpu-wsl-py314.txt) as a pip constraints file for CPU
tests with Python 3.14 on Ubuntu under WSL. Install an Ascend-enabled TileLang
build with its bundled TVM for compiler tests.

For NPU execution, select the Torch, torch_npu and compiler versions together
using the [compatibility guide](../docs/compatibility.md).
